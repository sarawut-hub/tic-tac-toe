# Tic-Tac-Toe Online Game 🎮

## คำอธิบาย
เกม Tic-Tac-Toe แบบ multiplayer ผ่านเว็บ
Deploy บน Render.com

## เทคโนโลยี
- Python (Backend: FastAPI/WebSocket + SQLite)
- React (Frontend)
- WebSocket

## วิธีติดตั้งและรัน
```bash
# Backend - ดู backend/.env.example และรัน
python -m uvicorn main:app --reload
```
